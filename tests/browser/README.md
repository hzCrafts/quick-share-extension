# 媒体布局浏览器回归

运行 `pnpm test:media-layout`。需要 Node.js、npx 及 Playwright CLI 可使用的 Chromium/Chrome；命令通过 npx 调用 CLI，首次运行可能需要安装其运行环境。不使用用户已登录的浏览器资料。

该命令自动启动本地 Vite 和独立浏览器，完成后关闭；失败返回非零退出码。JSON 报告与 PNG 保存到 `.output/media-layout-regression/`，不创建新的扩展测试目录。

检查使用生产 ShareCard、X 适配器的原生引用提取和生产 exporter，不调用第三方帖子接口。媒体为离线 SVG，浏览器实际计算布局，不能用 happy-dom 的 DOM 断言代替这些几何检查。

覆盖范围：

- 2、3、4 个附件的全部图片／视频排列；5、6、9 个媒体的全图片、全视频及单视频位置等代表组合。
- 横横、竖竖、横竖、竖横、方形、超宽／超高比例；缺失、零、负数和非有限比例；视频数据更新后的布局切换。
- 三个主题，主帖、原生引用、评论引用，主帖与引用同时带媒体，以及窄预览。
- 校验顺序、格子填充、行列位置、重叠、越界、视频按钮中心、双视频等高比例；调用 exporter 做 640px × 2.5 倍真实 PNG 导出。

这是可枚举布局规则的回归，不代表所有真实网站 DOM、所有浏览器版本或网络图片加载失败场景均已覆盖。实际网页的提取问题仍须用相应 DOM fixture 补测。
